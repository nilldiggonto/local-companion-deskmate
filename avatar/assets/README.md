# Avatar assets

Drop an animated GIF named `avatar.gif` in this folder and the avatar will
use it automatically instead of the drawn orb (restart the app after).

What makes a good avatar GIF:
- **Transparent background** (essential -- otherwise you get a square box)
- Roughly **square**, around 128x128 to 256x256 px
- A subtle **idle loop** (breathing, blinking, floating) looks best
