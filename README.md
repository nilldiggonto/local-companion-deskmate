# Self-Learning Desktop Avatar

A floating desktop avatar for Windows, powered by a fully local LLM (via
Ollama). No external AI APIs (OpenAI, Anthropic, etc.) are called at runtime.

The avatar learns in two ways:
- **Memory** -- remembers facts from conversations and recalls them later.
- **Actions** -- watch a sequence of clicks/keystrokes once, then replay it
  on command by name.
